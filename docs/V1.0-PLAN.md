# V1.0 release scope

- Builder Pro: 4x7 editable board, mirror, items, roles, trait activation, TFTC2 share codes.
- Bilingual shell and data display foundation (Chinese default, English switch).
- Image import handoff preserves positioning and can hand carry/item metadata to Builder.
- Cloud workspace sync with Supabase Auth + RLS-backed per-user JSON workspace.
- OP.GG-style item explorer and enlarged Windows desktop typography from V0.8.4.
- `dev` validated by GitHub CI only; Vercel production deploys from `main`.
